兵種の三すくみ

兵種の相性資料から転記

基本の相性は 盾 → 槍 → 弓 → 盾。矢印は「有利に攻撃できる方向」を示す。

相性 意味
盾 → 槍 盾は槍に対して有利
槍 → 弓 槍は弓に対して有利
弓 → 盾 弓は盾に対して有利

ここが重要：孫悟空は、兵種相性だけで戦闘結果に大きな差が出るとは考えていない。ただし、育成・編成と組み合わさることで影響が大きくなり、ステータス次第では差がさらに広がる。実戦では兵種比率、英雄スキル、攻防・殺傷・HP、盾が維持できる時間まで合わせて判断する。だから「弓が盾に強い＝弓だけ増やせばいい」にはならない。

まずは兵士に何をさせたいのかを考える。

孫悟空の見解

3 兵種の役割

実際のゲーム画像ではなく、役割を表すオリジナルの模式図。

盾兵耐久力が最大の強み

敵の攻撃に耐え、できる限り戦闘ターンを増やして、槍兵・弓兵がダメージを与える機会を作る。盾が早く崩れると、槍・弓が攻撃できる回数は極端に減る。

槍兵奇襲と火力

高い火力を持ち、兵士の奇襲スキルで盾を越えて弓兵へ直接ダメージを与えられる。防御・HPは低く、奇襲も確率発動なので、発動が少ない戦闘では期待した効果を出しにくい。

弓兵高火力と追加攻撃

全兵種の中でも高い火力が特徴。1ターンに2回攻撃する能力（発動確率10%）がある一方、防御・HPが低く、槍兵の奇襲に注意が必要。

ゲーム内の実際の兵士画像（煌耀槍兵）

以前共有されたゲーム内スクリーンショットから掲載。画像は「煌耀槍兵」のもので、盾兵・弓兵の実画像は未収録。

T11 → T12 の変化

T11 → T12ゲーム内で確認済み

全兵種で攻撃・防御・殺傷・HPがそれぞれ +3、総力は 148 → 178、負荷は 400 → 420、速度は 11 のまま。

攻撃と殺傷、防御と HP

どちらも重要だが、役割は同じではない。

孫悟空式では兵種の長所を軸に育て、格上との戦いで攻防を大きく離されないことも重視する。この優先思想には基礎値の比較と実戦経験に基づく判断が含まれる。

盾の防御と HP のどちらを優先するかなら、孫悟空は防御を選ぶ。防御は追加ステータスによる伸びが大きくなりやすいと考えているため。

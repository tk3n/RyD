ガイド

兵種の相性から、比率、戦報、育成、英雄の選び方まで。全部を一度に読む必要はない。自分の目的に合うところから。

はじめて

  • 初めての人はここから兵種の役割を知る → 育て方を選ぶ → 育成の順番を決める。3 ステップを 1 ページに。

兵種

  • 兵種の相性・役割・スキル盾・槍・弓の三すくみと役割、FC10 の基礎ステータス（T11 / T12）、兵士スキル 12 種。

戦い方

  • 戦い方を考える兵種の比率を決める、テント戦で試す、戦報を振り返る。実戦と検証を行き来するためのハブ。
  • 兵種比率の考え方433・424・523 の使い分けと、比率を目的から決める考え方。
  • テント戦検証孫悟空式1000 人対 1000 人のテント戦で、比率・スキルの発動・削れ方を試して、判断の基準を作る。
  • 戦闘レポートの読み方孫悟空式英雄を見る → 削り方・削られ方を見る → スキルの発動を見る。連撃の見方と、ウルカヌス / カーラの役割による評価の違い。
  • T12 専用｜集結研究T12 の集結研究スキル 3 種と、盾弓型に槍をどれだけ入れるかを試す槍比率スライダー。

育成

  • 育成の考え方と優先順位対人戦に共通する 4 つの考え方、戦闘育成の基本優先順位、英雄装備・ペット・島・研究の方針。
  • 神話装備の強化順孫悟空式ミスリルの部位別強化順（盾 / 槍 / 弓）、色段階、止めるレベル、精錬の最低条件、ミスリルとエナジー石の育成軸。
  • 熊特化孫悟空式熊狩り専用の育成。完全熊特化と弓先行、ミスリルは攻撃優先、残りのエナジー石はゴーグル・ブーツへ。
  • 盾弓特化孫悟空式対人戦の盾弓特化。弓の攻撃・殺傷で盾を削り、盾の防御・HP で時間を作り、弓の防御・HP で奇襲に耐える。
  • 盾槍特化孫悟空式対人戦の盾槍特化。盾で守り、槍の奇襲で弓を狙う。550・640・460・541 を相手次第で使い分け、駐屯は盾の補充を軸に考える。
  • バランス型孫悟空式全兵種がカンストすれば、最終的にはみんなバランス型になる。育成途中の優先順位と、育ち切った完成形を分けて考える。

英雄

  • 英雄の選び方英雄スキルの使い方（集結・防衛）。戦闘を成立させる 3 段階のどこを補えるかで採用を考える。

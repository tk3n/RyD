使い方の案内

育て方を選んで、盾・槍・弓の装備を入れてね。

素材が貯まって、次にどの部位を上げるか迷ったとき。

使い方を3手順で見る
  1. 目指す育て方を選ぶ。バランス・盾弓・盾槍・熊特化から選んでください。
  2. 盾・槍・弓の装備を全12部位入力する。装備画面の右上の「＋」がミスリル（神話Lv.）、右下の「Lv.」がエナジー石（精錬Lv.）。
  3. 全12部位が揃ったら診断する。次に上げる兵種・部位と、その先3つの目標が分かります。

自分のサーバーの世代

選んだ世代までに登場する英雄と、初期英雄を出します。実際の解放状況はゲーム内で確認してください。

編成から左英雄を探す

3人を選んで、左英雄を探す。集結・防衛の装備効果も合わせて比較。

編成の案内

3人を選び、足りない効果から左英雄を探す。

集結・防衛のスキルと装備を、一緒に比較したいとき。

判断のポイント
  • 自分の世代と、集結・防衛の場面を選ぶ。
  • 盾・槍・弓の3人を選び、足りない効果から左英雄を探す。
  • 専用装備の適用場面と、確率・対象兵種も確認する。

世代は右上の世代チップで変えられる。選んだ世代までの英雄と、初期英雄を使える。

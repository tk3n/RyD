質問

盾を増やせば勝てる？

解説

耐える時間は増える。でも、刺す槍・弓が減れば火力も落ちる。比率はその両方を見て決めよう。

今の比率が合っているか、相手にどう合わせるか迷ったとき。

判断のポイント

  1. 1比率は固定の正解にせず、自分の育成と目的で決める。
  2. 2一つずつ条件を変え、削れ方と残り方を比べる。
  3. 3連撃では、次の集結が戦う相手まで考える。

研究の出発点｜「盾 50%」という前提を疑う

盾も攻撃し、槍・弓も敵を削ることで味方を守る。防御と攻撃は単純に二分できない。

孫悟空の見解

盾兵を増やせば守りが固くなり、戦闘ターンも伸びやすくなる。一方、攻撃役の槍・弓が減って火力は落ちる。耐える時間と、相手を削る力の両方を見て判断する。
